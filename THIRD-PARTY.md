# Other people's work

vobuda is built on libraries other people wrote and gave away. Nearly all
of them ask for one thing in return: that their name travels with the
program. This file is that.

This page names the ones you can see. The **complete** list — every crate
and every package in a build, with its version, its licence and its
copyright line, followed by the text of each licence — is `NOTICES.md`,
generated by `scripts/notices.py` and shipped inside the program: the
application menu has "What vobuda is built on", and it opens as a block
like any other file. Nothing here is modified; every one is used as
published.

Nothing vobuda is built on is copyleft over vobuda's own source: no GPL, no
AGPL, no SSPL. Five crates are MPL-2.0, whose copyleft is file-level and
reaches only their own files.

Nor does anything here restrict what vobuda may be: every licence in this
file permits use "for any purpose", with or without a fee. That includes the
icons — ISC, the same terms as MIT in different words — so the set does not
have to be revisited if the program is ever sold. Part of Lucide is derived
from Feather (MIT, Cole Bemis); both notices ship in `NOTICES.md`.

The brand logos are a separate matter and are treated as one. Their files are
CC0 — waived into the public domain, no attribution owed and no fee — but a
logo is a trademark whatever its file says, and a trademark belongs to its
owner. So vobuda ships no logo on any button of its own: the set is there to be
chosen from, and a person putting a mark on their own button is naming the
thing they use, which is what a mark is for.

## The ones with conditions

Five crates are under **MPL-2.0**, which is copyleft file by file: if we
changed one of their files, that file would have to be published. We have
not changed any of them — they are used exactly as released, and their
source is public at crates.io.

  `cssparser`, `cssparser-macros`, `dtoa-short`, `option-ext`, `selectors`

`caniuse-lite` is CC-BY-4.0 and is used only while building, to know what
browsers support. Its data is not part of the program.
